    subscribeServerNotifications

    • subscribeServerNotifications(method: string): Promise<void>

      Subscribe to notifications from the LSP server with the specified method. Notifications which have been subscribed to will be fired through InfoviewApi.gotServerNotification. This may be called multiple times, in which case the editor must count the subscriptions and only stop firing events when unsubscribe has been called the same amount of times.
